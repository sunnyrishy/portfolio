# Portfolio, Sunny Rishy Vardhan

An interactive town you can walk around. Each landmark opens a part of my story: projects, merged open source work, experience, education, skills and contact.

Live at [sunnyrishy.vercel.app](https://sunnyrishy.vercel.app)

## Stack

Vite, React 18, Tailwind CSS 3, Framer Motion. The town is hand drawn SVG.

## Run it

```bash
npm install
npm run dev
```

All copy lives in `src/data.js`. The landmark layout lives in `src/world/landmarks.js`.
